Why Agentic AI? The Paradigm Shift

Traditional chatbots simply answer prompts. Agentic AI plans, uses tools, takes action, and iterates to achieve complex goals.

Conventional Generative AI
  • ✕ Single turn prompt-and-response
  • ✕ Cannot interact with external tools or databases
  • ✕ Passive knowledge generation without action
  • ✕ Requires continuous human supervision at every step
VS
Agentic AI (What You Will Master)
  • ✓ Autonomous multi-step goal planning & reasoning
  • ✓ Uses external tools, APIs, web search & code execution
  • ✓ Self-reflection, verification, and automated error-correction
  • ✓ Executes full complex workflows with minimal human oversight

📌 Event Concept & Objectives

The Agentic AI Workshop introduces participants to how AI agents differ fundamentally from conventional AI models, demonstrating how agents can be designed to perform tasks with minimal human intervention.

You won't just sit and listen: you will write code, invoke tools, build reasoning loops, and deploy practical AI agents. The workshop concludes promptly at 3:00 PM, immediately transitioning into the hackathon problem statement briefing!

🎯 5 Key Focus Areas

01

Fundamentals of Artificial Intelligence & Agentic AI

Understanding foundation models, tokenization, contextual reasoning, and the emergence of autonomous behaviors.

02

Understanding AI Agents & Agentic Workflows

Deconstructing agent topologies: Single-agent vs Multi-agent coordination, orchestration patterns, and state management.

03

How AI Agents Perform Tasks

The core loop: Observation → Thought / Reasoning → Action Plan → Execution → Evaluation.

04

Tool Usage & Task Execution

Equipping agents with tools: API calls, database lookups, code execution, web scrapers, and dynamic schema parameters.

05

Building Practical AI Agents

Hands-on lab where every participant develops, debugs, and runs a working agent ready for real-world tasks.
